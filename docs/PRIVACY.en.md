# OmniPulse privacy

**[Español](PRIVACY.md) · English**

OmniPulse may process nearby Bluetooth advertisements, visible Wi-Fi network names supplied by a compatible sensor, signal strength, channel/frequency data, timestamps, and optional user-authorized location.

- History is stored locally with SwiftData.
- There is no OmniPulse account system, advertising analytics, or cloud history sync.
- CSV/PDF export occurs only after an explicit user action.
- Sensors generate ephemeral pseudonyms and do not transmit clear BSSID/MAC addresses.
- Bluetooth, location, and local-network permissions remain under operating-system control.

Use OmniPulse only in locations, networks, and devices you own or have explicit permission to inspect.
