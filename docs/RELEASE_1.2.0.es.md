# OmniPulse 1.2.0

**Español · [English](RELEASE_1.2.0.md)**

- Calibración de RSSI independiente para cada sensor ESP con corrección persistente de ±20 dB.
- Estado del sensor en vivo: observaciones, uptime, memoria libre, señal, hardware y firmware.
- Retención local por antigüedad y número máximo de registros.
- Firmware ESP32 1.4.0 con diagnóstico y rollback ante validación de arranque fallida.
- AltStore y Sideloadly continúan disponibles junto con la instalación directa mediante Xcode.
