# Security

**[Español](SECURITY.md) · English**

Do not publish vulnerabilities, credentials, MAC addresses, locations, or network screenshots in a public issue.

To report a vulnerability, use **Security → Report a vulnerability**. Include the affected version, platform, impact, and minimum reproduction steps, replacing sensitive identifiers with fictitious values.

Radio features must be used only on networks, spaces, and devices you own, administer, or are explicitly authorized to inspect. OmniPulse is not designed to intercept traffic, obtain credentials, or bypass access controls.
