# Seguridad

No publiques vulnerabilidades, credenciales, direcciones MAC, ubicaciones ni capturas de redes en un issue público.

Para informar una vulnerabilidad, utiliza **Security → Report a vulnerability** en este repositorio. Incluye la versión, plataforma, impacto y pasos mínimos para reproducirla, sustituyendo cualquier identificador sensible por valores ficticios.

Las funciones de radio deben utilizarse únicamente sobre redes, espacios y dispositivos propios o expresamente autorizados. OmniPulse no está diseñado para interceptar tráfico, obtener credenciales ni eludir controles de acceso.
